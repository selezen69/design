# Публикация сайта на Timeweb Cloud — пошаговая инструкция

Инструкция рассчитана на человека без технического опыта. Каждый шаг — это
действие в веб-панели или одна команда, которую нужно скопировать целиком.

Ничего из этого не выполняется автоматически — сайт не будет опубликован и
деньги не будут списаны, пока вы сами не пройдёте эти шаги.

## Что понадобится

- Аккаунт на [GitHub](https://github.com) с этим проектом.
- Аккаунт на [timeweb.cloud](https://timeweb.cloud) с привязанным способом оплаты.
- Telegram — для создания бота, который будет присылать вам заявки.

---

## Шаг 1. Выложить код на GitHub

Если проект ещё не в GitHub (или в нём нет последних изменений) — это нужно
сделать в первую очередь, Timeweb будет брать код оттуда. Если вы работаете
с этим через Claude Code — просто попросите закоммитить и запушить текущие
изменения в отдельном сообщении.

## Шаг 2. Создать Telegram-бота для уведомлений о заявках

1. В Telegram найдите бота **@BotFather** и напишите ему `/newbot`.
2. Следуйте подсказкам (попросит придумать имя и username бота).
3. В конце BotFather пришлёт **токен** — строку вида `123456789:AAExampleTokenHere`.
   Сохраните её, она понадобится на шаге 6.
4. Напишите вашему новому боту любое сообщение (например «привет») — без
   этого бот не сможет писать вам первым.
5. Откройте в браузере (вместо `<ТОКЕН>` вставьте токен из шага 3):
   `https://api.telegram.org/bot<ТОКЕН>/getUpdates`
6. В открывшемся тексте найдите `"chat":{"id":ЧИСЛО` — это число и есть ваш
   **chat_id**. Сохраните и его.

## Шаг 3. Создать базу данных PostgreSQL

1. В панели [timeweb.cloud/my](https://timeweb.cloud/my) откройте раздел
   **«Базы данных»** → **«Добавить»**.
2. Выберите **PostgreSQL**, версию можно любую из предложенных (например 17).
3. Выберите регион (например «Москва»).
4. Выберите минимальный тариф — для такой нагрузки этого достаточно.
5. Задайте пароль и имя базы, например `design_portfolio`. Пароль скопируйте
   в надёжное место.
6. Дождитесь создания базы (обычно несколько минут). Откройте карточку базы
   и скопируйте: **хост**, **порт**, **пользователя**, **пароль**, **имя базы**.

## Шаг 4. Создать таблицы в новой базе

На своём компьютере уже установлен `psql` (см. [db/README.md](db/README.md)).
Откройте PowerShell и выполните команду, подставив свои значения из шага 3
вместо `ПОЛЬЗОВАТЕЛЬ`, `ПАРОЛЬ`, `ХОСТ`, `ПОРТ`, `ИМЯ_БАЗЫ`:

```
& "C:\Program Files\PostgreSQL\17\bin\psql.exe" "postgresql://ПОЛЬЗОВАТЕЛЬ:ПАРОЛЬ@ХОСТ:ПОРТ/ИМЯ_БАЗЫ?sslmode=require" -f db\schema.sql
```

Эта команда один раз создаёт 4 пустые таблицы. `db/seed.sql` (тестовые данные)
применять не обязательно — реальные заявки будут приходить из формы на сайте.

## Шаг 5. Создать приложение в Timeweb Cloud App Platform

1. В панели timeweb.cloud/my откройте раздел **«Приложения»** → **«Создать»**.
2. Подключите GitHub-репозиторий с этим проектом (потребуется один раз
   авторизовать Timeweb в GitHub).
3. Выберите тип приложения **Node.js / Backend**.
4. Команда сборки (build command): `npm run build`
5. Стартовую команду площадка обычно определяет сама (по файлу `server.js`
   в корне проекта). Если попросит указать вручную — впишите: `node server.js`
6. Порт приложения: `3000`.

## Шаг 6. Задать переменные окружения

В настройках приложения найдите раздел **«Переменные окружения»**
(Environment variables) и добавьте:

| Имя | Значение |
|---|---|
| `DATABASE_URL` | `postgresql://ПОЛЬЗОВАТЕЛЬ:ПАРОЛЬ@ХОСТ:ПОРТ/ИМЯ_БАЗЫ` (из шага 3) |
| `PGSSL` | `true` |
| `TELEGRAM_BOT_TOKEN` | токен из шага 2 |
| `TELEGRAM_CHAT_ID` | chat_id из шага 2 |

Полный список переменных с описанием — в файле [.env.example](.env.example).

## Шаг 7. Запустить публикацию

Нажмите **«Развернуть»** / **«Deploy»** и дождитесь статуса **«Работает»** /
**«Running»**. Если сборка упадёт с ошибкой — в панели будет вкладка с логами
сборки, там будет видно, на каком шаге и почему.

## Шаг 8. Проверить, что всё работает

1. Откройте адрес, который выдаст Timeweb (вида `https://ваш-проект.twc1.net`).
2. Долистайте до формы заявки, заполните и отправьте тестовые данные.
3. Проверьте:
   - в Telegram от бота пришло уведомление;
   - заявка сохранилась в базе — можно проверить командой (та же строка
     подключения, что и в шаге 4):

     ```
     & "C:\Program Files\PostgreSQL\17\bin\psql.exe" "postgresql://ПОЛЬЗОВАТЕЛЬ:ПАРОЛЬ@ХОСТ:ПОРТ/ИМЯ_БАЗЫ?sslmode=require" -c "SELECT * FROM leads ORDER BY created_at DESC LIMIT 5;"
     ```

## Шаг 9 (по желанию). Подключить свой домен

В настройках приложения — раздел **«Домены»** — добавьте домен и пропишите
DNS-записи по инструкции, которая появится на экране.

## Шаг 10 (по желанию, но рекомендуется). Уведомления о сбоях

Зарегистрируйтесь на [uptimerobot.com](https://uptimerobot.com) (бесплатно),
добавьте монитор на адрес сайта — придёт письмо, если сайт перестанет
отвечать.

---

## Если что-то не работает

- **Ошибка при сборке** — откройте вкладку логов сборки в панели Timeweb,
  там будет текст ошибки.
- **Сайт открывается, но заявки не сохраняются** — проверьте, что `DATABASE_URL`
  и `PGSSL=true` заданы верно (шаг 6) и что таблицы были созданы (шаг 4).
- **Уведомления в Telegram не приходят** — проверьте `TELEGRAM_BOT_TOKEN` и
  `TELEGRAM_CHAT_ID`, а также что вы написали боту хотя бы одно сообщение
  (шаг 2, пункт 4) — без этого он не может писать вам первым.
